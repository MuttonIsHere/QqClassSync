# QQ 调课同步 v1.3.0 —— 全渠道：QQ + 小橙看班

> 老师发 QQ 也好，在小橙看班发「全屏播报 / 班级通知」也好，大屏都能自动改课表。

## 🆕 新增：跨插件联动（与「小橙看班联动」打通）

```
QQ Toast ───────┐
                ├─→ QqClassSync（唯一大脑：正则 → AI → 临时层 → 大屏提醒）
小橙看班消息 ───┘        ↑
                    XiaoChengLink：读 Data.idb → 转发（含 30 秒兜底轮询）
```

- **桥接契约**：公开静态方法 `QqClassSync.Bridge.TiaokeBridge.Submit(text, source)`；
  对方插件通过反射按类型名调用，**不编译期互相引用**，任一方升级都不会让另一方加载失败。
- **外部消息独立队列**：与 QQ Toast 走同一条解析管线（正则优先 → AI 兜底 → 改课表 → 提醒），
  监听关闭时自动丢弃，避免过期指令被补执行。
- **来源标注**：非 QQ 来源的提醒正文带 `【来源：小橙看班】`，老师一眼能看出消息从哪来。
- **确认指令通用**：AI 待确认时，`#确认` / `#放弃` 发在 QQ 或小橙看班都能生效。

## 📦 配套版本

| 插件 | 版本 | 说明 |
|---|---|---|
| QQ 调课同步 | **1.3.0.0** | 本次发布 |
| 小橙看班联动 | **2.0.2.0** | 新增转发 + 兜底轮询（`tiaokeLinkPollSeconds`，默认 30 秒） |

## ✅ 验证

- 两个插件同时加载：`qq.classsync 1.3.0.0` + `xiaocheng.link 2.0.2.0`
- 真机实测：在小橙看班发消息 → 大屏弹待确认（标注来源：小橙看班）→ 发 `#确认` → 课表翻转
- QQ 来源链路回归正常（正则消息 + AI 模糊解析都不受影响）

## 🚀 升级

1. 先装/升级 **小橙看班联动 v2.0.2**（可选，不装则只有 QQ 一个来源）
2. 再覆盖安装 **QQ 调课同步 v1.3.0**
3. 重启 ClassIsland 一次即可（两个插件都在启动时初始化）

## ⚠️ 说明

- 小橙看班的兜底轮询每 30 秒会复制一次 `Data.idb` 并运行读取脚本；课堂机觉得开销大时，
  把 `tiaokeLinkPollSeconds` 设为 `0`（关闭）或调大，只保留「弹窗触发」路径。
- 两个插件独立发布，请保持两个都更新到上表版本，避免桥接契约不一致。
