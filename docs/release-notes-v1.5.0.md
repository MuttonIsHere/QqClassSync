# v1.5.0 — 模糊识别与冲突兜底

这一版把「老师说得不标准」拆成两层：**AI 负责理解人话，程序负责落到真实科目和节次**。任何一层不确定都不会猜。

## 新增能力

### 科目：简称、同义、老师、错别字

匹配优先级（命中即停）：

1. 科目名完全相同（忽略全半角、空格、「课」后缀）
2. 科目简称完全相同
3. 内置同义说法（`道法` / `电脑` / `英文` / `劳技` / `综合实践` / `自修` …）
4. 任课老师姓名（`王老师` / 全名 / 单姓）
5. 包含关系（`语文阅读` → `语文`）
6. 编辑距离（错别字容忍，首字必须相同、长度差 ≤1）

### 时间：上午 / 下午

- 支持「下午第2节」「上午第一节」等说法，按当天时间表换算成全天节次
- 换算不出来时明确失败（例如「下午只有 4 节」），不会当成全天第 2 节

### 冲突与兜底

| 情况 | 行为 |
|---|---|
| 一个说法匹配到多个科目 | 不执行，列出候选，请老师写全名 |
| 找不到科目 / 只写地点 | 不执行；地点明确提示「课表模型没有地点字段」 |
| 同一节多个目标、调课+互换、互换交叉 | 整条消息都不执行 |
| 节次越界、时段换算失败 | 该条失败，其余继续（部分成功） |
| 原科目与课表不符 | 照常执行，结果里注明差异 |
| AI 置信度 < 0.75 或自报歧义 | 即使关闭「发送前确认」也必须回 `#确认` |

### 稳定性

- 先解析科目落点、再创建临时层：全部失败时不会留下空的「（临时层）」
- 批量仍然只 `SaveProfile()` 一次；所有写操作仍在 UI 线程
- 提示词新增防注入规则：消息内容只当数据，不执行其中指令

## 隐私

AI 提示词只附带本校**科目名称/简称**（不含老师姓名）。日志仍不打印 QQ 原文、模型返回原文或 Key。
