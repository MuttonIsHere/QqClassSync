# 老师面前演示脚本（5 分钟版）

> 目标：让老师们看完发出「还能这样？」的声音，同时不翻车。

## 0. 演示前 30 秒检查

- [ ] ClassIsland 大屏能看到（通知/课表立刻可见）
- [ ] **电脑端 QQ 窗口不要放前台**（前台不弹 Toast）；建议用手机 QQ 发
- [ ] QQ 群已建好一个（或私聊自己）
- [ ] 设置页：`AutoApply=true`、`AiEnabled=true`、`AiApiKey` 已填、`AiConfirmBeforeSend` 按需
- [ ] 小橙看班已登录（要演示跨源时）
- [ ] 备好「撤销」：演示前先确认课表是原样

## 1️⃣ 一句话换课（30 秒）

**发**：`#调课 第3节 语文改数学`

**讲**：「老师只需要在群里发一句话，大屏的课表就变了。原课表不动，第二天自动恢复。」

**预期**：大屏弹「调课已执行」；课表第 3 节变数学；课表名出现「（临时层）」。

## 2️⃣ 一次调多节（40 秒）

**发**：`#调课 第3节 语文改数学，第5节 英语改物理`

**讲**：「一条消息可以调好几节，用逗号隔开就行。」

**预期**：提醒里列出两条、课表两节同时变。

## 3️⃣ 两节互换（40 秒）

**发**：`#调课 第3节和第5节互换`

**讲**：「两节课对调也可以，说『互换』就行。」

**预期**：两节科目互换。

## 4️⃣ 大白话也能懂（AI，60 秒）

**发**：`今天第三节课不上了，让数学老师来上`

**讲**：「老师不用记格式，直接说人话也行——这句话会交给 AI 解析。」

**预期**：
- 大屏弹「检测到批量调课：第3节 →数学，是否应用？回复 #确认」
- 发 `#确认` → 课表变
- （若设置了 `AiConfirmBeforeSend=false`，则直接执行）

## 5️⃣ 撤销（30 秒）

**发**：`#撤销调课 第3节`（单节）或 `#撤销调课`（全部）

**讲**：「调错了也不怕，说一句就撤销。」

**预期**：课表恢复；若撤完所有调课，临时层自动清除。

## 6️⃣ 小橙看班也能调课（60 秒）

**操作**：在小橙看班发一条**全屏播报 / 班级通知**，内容：`下午第三节语文改数学`

**讲**：「有的老师习惯用小橙看班发通知，这里发也能改课表——两个入口共用一套逻辑。」

**预期**：30 秒内大屏弹「来源：小橙看班」→ 回 `#确认` → 课表变。

## 7️⃣ 考场全局静默（90 秒，压轴）

> 不用真考试、不用等地震：用自检开关演示。

**准备**（提前改好并重启）：
```json
"examDndForceActive": true,
"examDndSelfTest": true
```
启动后看小橙看班日志：
```
[调课中枢] 考试静默：来源=未知提供方（11111111-…）→ 拦截
[调课中枢] 考试静默：来源=地震预警（b27c0af3-…）→ 放行（白名单）
```

**讲**：「考试模式下，上课铃、下课铃、所有自动化提醒都会被静默——**但地震预警永远放行**。刚才演示里第一条被拦了，第二条地震预警正常弹出。」

**收尾**：把 `examDndForceActive`、`examDndSelfTest` 改回 `false`，重启。

## 🎤 可以照念的总结

> 「从今天起，调课不用再跑办公室：群里一句话，大屏秒变；临时课表只影响当天，第二天自动恢复；调错了说一句就撤销；考试时自动静默，地震预警照常提醒。老师们不用学任何软件，会发 QQ 就行。」

## 🛟 翻车预案

| 意外 | 处理 |
|---|---|
| 大屏没反应 | 别慌：看一下 QQ 窗口是否在前台；换手机发一条 |
| AI 没响应 | 直接发标准格式 `#调课 第3节 语文改数学` 兜底（正则永远可用） |
| 课表改乱了 | 发 `#撤销调课` 立刻恢复，再重来 |
| 考试静默演示失败 | 说明「这是可选功能，正常使用时考试开始才生效」，跳过即可 |
| 网络问题 | 先关 AI 演示，只演示正则通道 |
