# 终极装机清单（QqClassSync v1.4.1 + XiaoChengLink v2.1.0）

> 目标：一台教室电脑，装上两个插件，实现「QQ / 小橙看班 → 大屏自动改课表」+「考试模式全局静默（地震预警放行）」。

## 一、环境要求

| 项 | 要求 | 本机实测 |
|---|---|---|
| 操作系统 | Windows 10 2004（19041）及以上 / Windows 11 | Windows 11 26300 ✅ |
| ClassIsland | **2.1.0.1** | ✅ |
| .NET 运行时 | **self-contained 安装包已自带 .NET 8，无需单独安装**；若为 framework-dependent 安装，则需 .NET 8 Desktop Runtime x64 | 自带 coreclr.dll ✅ |
| QQ | NT QQ，已登录、开启消息通知、Windows 允许 QQ 通知 | ✅ |
| 小橙看班 | inArt_PC（需要「小橙看班通道」时装） | ✅ |
| 权限 | 能写入 ClassIsland 安装目录（管理员） | ✅ |

## 三、安装顺序（务必按这个来）

| 步骤 | 操作 | 说明 |
|---|---|---|
| 0 | **备份** `<ClassIsland>\data\Plugins\QqClassSync\` 与 `data\Plugins\xiaocheng.link\` | 出问题可整目录回滚 |
| 1 | 安装 **XiaoChengLink v2.1.0** | 先装它，可先单独验证原有窗口/考试提醒 |
| 2 | 安装 **QqClassSync v1.4.1** | 装完它，桥接在运行时自动连接 |
| 3 | **重启 ClassIsland** | 插件 DLL 启动时加载，覆盖安装必须重启 |
| 4 | 打开「应用设置 → 插件 → QQ 调课同步」配置 | 填 API Key、开 AI（设置热更新，**不用再重启**） |
| 5 | 验证（见第五节） | 两条通道各发一条测试消息 |

> 两个插件必须都装且版本达标：`qq.classsync 1.4.1` + `xiaocheng.link 2.1.0`。
> 只装 QQ 调课同步 = 只有 QQ 通道；只装小橙看班 = 只有提醒，没有改课表。

## 四、必须配置的项

### QQ 调课同步（`data\Config\Plugins\qq.classsync\Settings.json`）

| 配置 | 推荐值 | 说明 |
|---|---|---|
| `Enabled` | `true` | 总开关 |
| `Keyword` | `#调课` | 老师习惯别的词就改 |
| `ScanIntervalSeconds` | `1` | 1–2 秒 |
| `AutoApply` | `true`（培训期可先 `false` 干跑） | 关掉只提醒不改课表 |
| `NotifyOnParseFailure` | `true` | 格式不对时提示 |
| `AiEnabled` | `true`（可选） | 要自然语言识别时开 |
| `AiApiKey` | 填你的 DeepSeek Key | **只存本机，不进仓库** |
| `AiBaseUrl` | `https://api.deepseek.com/v1` | 一般不动 |
| `AiConfirmBeforeSend` | `true` | AI 结果先确认，回 `#确认` 才执行 |

### 小橙看班联动（`data\Config\Plugins\xiaocheng.link\settings.json`）

| 配置 | 推荐值 | 说明 |
|---|---|---|
| `readMessageBodyFromDatabase` | `true` | 不读库则调课联动失效 |
| `tiaokeLinkPollSeconds` | `30` | 兜底轮询；机子吃力就调大或设 `0` |
| `examDndEnabled` | `true` | **考试中拦截提醒** |
| `examDndWhitelistProviderGuids` | `["B27C0AF3-C917-44DE-A61D-8010C3F3FB92"]` | 地震预警白名单（可加多个） |
| `examDndDryRun` | `false` | 首次可临时 `true` 跑一场观察日志 |
| `examDndForceActive` | `false` | 仅联调用，正式必须关 |
| `examDndSelfTest` | `false` | 仅联调用，正式必须关 |

## 五、装完验证（5 分钟）

1. **看日志**（`<ClassIsland>\data\Logs\` 最新日志）：
   ```
   此次会话已加载插件: … QQ 调课同步(qq.classsync,1.4.1.0) … 小橙看班联动(xiaocheng.link,2.1.0.0)
   [调课中枢] QQ 调课同步已启动（间隔 1s，关键词 #调课，自动应用 True）
   [调课中枢] 通知监听权限：Allowed
   ```
2. **QQ 通道**：群里发 `#调课 第3节 语文改数学` → 大屏弹「调课已执行」，课表变。
3. **小橙看班通道**：发一条全屏播报/班级通知「下午第三节语文改数学」→ 最多 30 秒弹「来源：小橙看班」→ 回 `#确认` → 课表变。
4. **撤销**：发 `#撤销调课 第3节` → 恢复。
5. **考试静默**（可选，用自检代替真实考试）：
   - 把 `examDndForceActive=true`、`examDndSelfTest=true` 写入配置 → 重启
   - 看小橙看班日志：
     ```
     [调课中枢] 考试静默：来源=未知提供方（11111111-…）→ 拦截
     [调课中枢] 考试静默：来源=地震预警（b27c0af3-…）→ 放行（白名单）
     ```
   - 验证完把这两个开关改回 `false` 并重启

## 六、常见问题

| 现象 | 排查 |
|---|---|
| 大屏没反应 | ① ClassIsland 是否运行；② 日志搜 `[调课中枢]`；③ QQ 是否真的弹了 Toast（窗口别在前台） |
| 弹「没有通知监听权限」 | Windows 设置 → 通知允许；重启 ClassIsland |
| 弹「调课失败」 | 日志有原因：科目名不匹配 / 今天没课表 / 节次越界 |
| 小橙看班消息不生效 | 检查 `readMessageBodyFromDatabase=true`、`tiaokeLinkPollSeconds>0`；等最多 30 秒 |
| AI 没反应 | 日志 `AI 调用失败（超时/网络错误/限流/HTTP 错误）` |
| 考试中地震预警也没弹 | 检查白名单 GUID；日志里看「来源=…→ 拦截」 |
| 考试中不该拦的被拦了 | 把该提供方 GUID 加进 `examDndWhitelistProviderGuids` |

## 七、回滚

1. 关闭 ClassIsland
2. 把 `data\Plugins\QqClassSync`、`data\Plugins\xiaocheng.link` 换回备份目录
3. 重启 ClassIsland
4. 若要彻底还原课表：课表页「清除临时层」

> 调课记录在 `data\Config\Plugins\qq.classsync\TempPatches.json`；卸载插件不影响档案本身。
