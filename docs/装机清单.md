# 明日装机清单（v1.3.0 + v2.0.2）

> 目标：一台教室电脑，装上「QQ 调课同步」+「小橙看班联动」，老师发 QQ 或发小橙看班都能自动改课表。

## 一、装机前准备

1. 确认 ClassIsland 能正常启动（示例版本 2.1.0.1）。
2. 到 GitHub Releases 下载两个插件包：
   - **QqClassSync v1.3.0**：`QqClassSync.cipx`
   - **XiaoChengLink v2.0.2**：`XiaoChengLink.cipx`
3. 先备份现有插件目录：
   ```
   <ClassIsland>\data\Plugins\QqClassSync\        （若已装旧版）
   <ClassIsland>\data\Plugins\xiaocheng.link\     （若已装旧版）
   ```
   建议整目录复制一份到 `data\Plugins\_backup_yyyyMMdd\`。

## 二、安装顺序（推荐）

| 步骤 | 操作 | 说明 |
|---|---|---|
| 1 | 安装 **小橙看班联动 v2.0.2** | 先装它，可以单独验证原有功能（窗口提醒/考试提醒）是否正常 |
| 2 | 安装 **QQ 调课同步 v1.3.0** | 后装它，桥接是运行期反射，顺序其实无所谓 |
| 3 | **重启 ClassIsland 一次** | 插件 DLL 在宿主启动时加载，覆盖安装后必须重启 |
| 4 | 打开 设置 → 插件 → QQ 调课同步，填 API Key、开「启用 AI 解析」 | 设置热更新，**不用再重启**，1 秒内生效 |

> 两个插件装同一个版本组合：`qq.classsync 1.3.0.0` + `xiaocheng.link 2.0.2.0`。

## 三、装完必做的验证（2 分钟）

1. **看日志**（`<ClassIsland>\data\Logs\` 最新日志）应出现：
   ```
   此次会话已加载插件: … QQ 调课同步(qq.classsync,1.3.0.0) … 小橙看班联动(xiaocheng.link,2.0.2.0)
   QQ 调课同步已启动（间隔 1s，关键词 #调课，自动应用 True）
   今天生效的课表：「周X」共 N 节
   通知监听权限：Allowed
   ```
2. **QQ 通道**：在 QQ 群里发 `#调课 第3节 语文改数学` → 大屏应弹「调课已同步」。
3. **小橙看班通道**：在小橙看班发一条全屏播报/班级通知，内容 `下午第三节语文改数学`
   → 最多 30 秒内大屏弹「检测到 AI 解析调课…（来源：小橙看班）」→ 发 `#确认` → 课表翻转。
4. **撤销**：发 `#撤销调课 第3节`（单节）或 `#撤销调课`（整天）。

## 四、关键配置总表

### QQ 调课同步（`data\Config\Plugins\qq.classsync\Settings.json`）

| 配置 | 默认 | 说明 | 建议 |
|---|---|---|---|
| `Enabled` | `true` | 总开关 | 保持开 |
| `Keyword` | `#调课` | 触发关键词 | 老师习惯别的词就改（如 `#换课`） |
| `ScanIntervalSeconds` | `1` | 通知轮询间隔（秒） | 1–2 秒足够；太大反应慢 |
| `AutoApply` | `true` | 关掉 = 干跑模式（只提醒不改课表） | 第一天培训可先关，确认解析正确再开 |
| `NotifyOnParseFailure` | `true` | 格式不对时是否提示 | 培训期开，稳定后可关 |
| `AllowedAppNames` / `AllowedAppIds` | QQ/TIM | 通知来源白名单 | 一般不用动 |
| `AiEnabled` | `false` | 启用 AI 模糊解析 | 需要自然语言识别时开 |
| `AiApiKey` | 空 | DeepSeek Key（只存本机） | 留空自动回退正则，不会崩 |
| `AiBaseUrl` | `https://api.deepseek.com/v1` | 接口地址 | 换供应商才改 |
| `AiConfirmBeforeSend` | `true` | AI 结果先确认再执行 | **建议保持开**，回复 `#确认` 才应用 |
| 调课日志 `TempPatches.json` | 自动生成 | 单节撤销的数据基础 | 保留最近 7 天，可手动清理 |

### 小橙看班联动（`data\Config\Plugins\xiaocheng.link\settings.json`）

| 配置 | 默认 | 说明 | 建议 |
|---|---|---|---|
| `tiaokeLinkPollSeconds` | `30` | 调课兜底轮询间隔（秒），0=关闭 | 课堂机吃不消就调大或设 0 |
| `readMessageBodyFromDatabase` | `true` | 读数据库正文总开关 | 关掉则调课联动失效 |
| `messageBodyFreshSeconds` | `30` | 正文新鲜度（只认多少秒内的新消息） | 与轮询配合，一般不用动 |
| `pollIntervalMs` | `1500` | 窗口扫描间隔（毫秒） | 1500–3000，越小越灵敏越耗 CPU |
| `notificationThrottleSeconds` | `12` | 提醒全局节流（秒） | 防止多窗口连发 |
| `cooldownSeconds` | `60` | 同一窗口冷却（秒） | 防止重复提醒 |
| `triggerOnWindowAppear` | `true` | 窗口出现时提醒 | 保持开 |
| `triggerOnVisualChange` | `true` | 画面变化时提醒 | 保持开（也是调课即时转发的触发条件） |
| `keywords` | 消息/提醒/作业… | 关键词列表 | 按学校习惯补 |

## 五、常见问题速查

| 现象 | 排查 |
|---|---|
| 大屏不弹 | ① ClassIsland 是否运行；② 日志有没有 `收到 QQ Toast` / `已把消息正文转发`；③ QQ 窗口别放前台 |
| 弹「没有通知监听权限」 | Windows 设置 → 通知允许；重启 ClassIsland |
| 弹「调课失败」 | 看日志：科目名不匹配 / 今天没课表 / 节次越界，提醒里会写原因 |
| 小橙看班消息不生效 | 等 30 秒兜底轮询；或确认 `readMessageBodyFromDatabase=true`、`tiaokeLinkPollSeconds>0` |
| AI 解析无反应 | 日志出现 `AI 调用失败（超时/网络错误/HTTP 错误）` → 检查 Key/网络/BaseUrl |
| 想临时关掉改课表 | 设置里关「自动应用调课」（干跑）或关「启用监听」 |

## 六、回滚

1. 关闭 ClassIsland
2. 把 `data\Plugins\QqClassSync` 和 `data\Plugins\xiaocheng.link` 换回备份目录
3. 重启 ClassIsland

> 调课记录在 `data\Config\Plugins\qq.classsync\TempPatches.json`，回滚插件不影响它；
> 若要彻底还原课表：ClassIsland 课表页「清除临时层」。
