# QQ 调课同步 v1.4.0 —— 批量调课

> 老师商量好之后，一条消息就能调多节课：换课、两节一起换、两节对调，甚至批量撤销。

## 🆕 批量调课

| 用法 | 例子 |
|---|---|
| 一次换多节 | `#调课 第3节 语文改数学，第5节 英语改物理` |
| 两节一起换同一科 | `#调课 第1节和第2节都换成自习` |
| 两节对调 | `#调课 第3节和第5节互换` |
| 批量撤销 | `#撤销调课 第3,5节` |
| AI 自然语言批量 | 「今天下午第1节和第2节都换成自习，另外第4节音乐改美术」 |

## 🧠 架构升级

**解析层**
- 正则：按逗号/分号/顿号切分，逐段识别；单条消息最多 10 条指令
- AI：System Prompt 改为输出 **JSON 数组**
  ```json
  [{"Lesson":3,"OriginalSubject":"语文","NewSubject":"数学"},
   {"Lesson":5,"OriginalSubject":"英语","NewSubject":"物理"}]
  ```
  互换用 `{"Lesson":3,"SwapWith":5}`；无调课意图输出 `[]`
- 兼容：`{"commands":[...]}` 包裹、单个对象、Markdown 围栏、前后多余说明文字

**执行层**
- 所有指令在 UI 线程内一次性处理（`Dispatcher.UIThread.InvokeAsync`）
- **只调用一次 `SaveProfile()`**，避免连续落盘卡死
- 互换会同时记录两条改动日志，单节撤销时两节都能正确回滚

**交互层**
- 待确认提醒列出全部指令：`1. 第3节 语文→数学；2. 第5节 英语→物理`
- 回 `#确认` 应用全部，`#放弃` 取消

**容错**
- 部分成功：正确的先改，错误的在大屏提示（如「第5节找不到科目「物理」，已跳过」）
- 节次越界、今天没课表、建临时层失败 → 都分别提示，不影响其它条目

## 🚀 升级

1. 下载 `QqClassSync.cipx` 覆盖安装
2. 重启 ClassIsland 一次
3. 无需改动设置；小橙看班联动保持 v2.0.2 即可

## ⚠️ 说明

- 单条消息最多 10 条指令（防止误发的超长文本把课表刷乱）
- 互换要求两节在今天的课表范围内，且科目不同
- 批量撤销按节次逐个回滚，撤销后若与源课表完全一致会自动清除临时层
